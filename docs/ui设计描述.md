# 医学影像工作站 UI 设计描述

## 1. 设计目标

本界面是一套面向医学影像阅片与三维建模的桌面工作站。核心任务是同时查看冠状位、轴位、矢状位切片，保持三视图联动定位，在切片上管理脊柱椎体分割/标注结果，并提供三维模型、仿真对象和显示参数的统一入口。

## 2. 画布与视觉基调

- **应用类型**：Windows 桌面端医学影像软件，适配鼠标、键盘和高分辨率显示器。
- **参考画布**：设计图约为 1704 × 916 px；建议响应式缩放，最小支持 1280 × 720 px。
- **背景与层次**：应用背景为冷白至浅灰，影像视图区使用纯黑背景；面板使用 1 px 浅灰边框、轻微阴影和 8~12 px 圆角。
- **字体**：中文优先微软雅黑/苹方，英文优先 Segoe UI；正文 12~14 px，模块标题 13~15 px，状态信息 11~12 px。
- **颜色**：工具选中和联动线使用浅蓝；方向、坐标和分割标签使用高辨识度红/黄/绿/多色标记。颜色只表达状态，不作为唯一信息来源。

## 3. 页面结构

采用“顶部导航 + 左侧主阅片区 + 右侧对象管理区 + 底部信息区”的固定结构。

```text
┌──────────────────────────────────────────────────────────────┐
│ 窗口标题/系统操作                                             │
├──────────────────────────────────────────────────────────────┤
│ 菜单栏：File Edit View Image Measure ... Help                 │
│ 快捷工具栏：打开、保存、撤销、视图/测量/分割等图标工具          │
│ 功能页签：View Measure Segment ... 3D Tools                  │
├──────────────────────────────┬───────────────────────────────┤
│  ┌──────────────┬─────────┐ │ Masks / Measurements /         │
│  │ 冠状位       │ 轴位    │ │ Annotations 对象列表           │
│  ├──────────────┼─────────┤ ├───────────────────────────────┤
│  │ 矢状位       │ 三维视图│ │ Parts / Analysis Objects ...   │
│  └──────────────┴─────────┘ │ 对象列表                       │
│  项目/文件信息日志            ├───────────────────────────────┤
│                              │ STLs / Polylines ...            │
│                              ├───────────────────────────────┤
│                              │ Contrast / Volume Rendering ... │
└──────────────────────────────┴───────────────────────────────┘
```

## 4. 顶部区域

### 4.1 窗口标题栏

显示当前项目名、文件名和软件名称，例如 `lixinghui - spine_edited_native (2).mcs - Mimics Medical 20.0`。右侧提供最小化、还原/最大化、关闭按钮；关闭前若有未保存修改，应弹出确认。

### 4.2 菜单栏

菜单依次为：`File`、`Edit`、`View`、`Image`、`Measure`、`Segment`、`Analyze`、`Align`、`Simulate`、`3D Tools`、`Script`、`Help`。菜单支持键盘访问、快捷键显示和禁用态。

### 4.3 快捷工具栏与功能页签

- 第一行是图标快捷工具栏，包含打开/导入、保存、撤销/重做、视图切换、测量、分割、对象操作等。
- 图标按钮点击热区 28~32 px；仅图标按钮必须提供悬浮提示和无障碍名称。
- 第二行是业务页签：`View`、`Measure`、`Segment`、`Cardiovascular`、`Pulmonary`、`Muscular`、`Mapping`、`Analyze`、`Simulate`、`3D Tools`。
- 当前页签使用浅蓝底和深色文字；切换页签不得破坏当前切片位置和对象选择。

## 5. 主阅片区

左侧约占页面 72% 宽度，采用 2×2 网格，视图区之间间距约 14~18 px。每个视图都是独立面板。

### 5.1 冠状位视图（左上）

黑色背景显示冠状位切片和多色椎体遮罩；左右显示 `R/L`，上下显示 `T/B`；中央显示红色水平十字定位线；右下角显示橙色坐标值，例如 `116.6992`；底部保留切片位置刻度条。

### 5.2 轴位视图（右上）

显示横断面影像，方向为上 `A`、下 `P`、左/右 `R/L`。绿色垂直线与橙色水平线构成交叉定位。支持滚轮逐层切片、拖拽平移、快捷键缩放。

### 5.3 矢状位视图（左下）

显示脊柱侧面影像，左右为 `P/A`，上下为 `T/B`。使用红色水平线和参考垂直线指示当前层面；右下角以绿色显示坐标值，例如 `124.9999`。拖动参考线时实时更新另外两幅切片。

### 5.4 三维视图（右下）

默认显示白色背景和 XYZ 方向坐标轴：Z 蓝色、Y 黄色、X 红色。右侧垂直工具条提供方向立方体、布局、旋转、平移、缩放、重置视角和显示模式切换。未加载对象时保留坐标轴和空状态；加载 STL、部件或体绘制后在此渲染。

### 5.5 视图区公共交互

- 单击视图获得焦点，焦点面板使用浅蓝外框。
- 滚轮浏览切片；`Ctrl + 滚轮` 缩放；中键平移；三维视图右键旋转。
- 双击恢复默认缩放和居中；工具栏提供显式“重置视图”。
- 十字线、方向标记、刻度和坐标读数始终位于影像上方。

## 6. 右侧对象与参数管理区

右侧约占页面 28% 宽度，按从上到下顺序排列；窗口变化时列表区域优先获得空间。

### 6.1 Masks / Measurements / Annotations

顶部使用 `Masks`、`Measurements`、`Annotations` 三个页签。`Masks` 列表字段包括名称、可见性、体素数、Low、Volume、面积和更多操作。示例对象为 `T10`~`T12`、`L1`~`L5`、`S1`、`Sacrum`。

- 每行左侧显示与遮罩一致的色块；眼睛图标切换可见性。
- 底部操作栏提供新增、编辑/重命名、复制、删除、导出/下载按钮；删除需二次确认。
- 支持多选、拖拽排序、名称搜索和右键菜单。

### 6.2 Parts / Analysis Objects / Reslice Objects / Soft tissue

通过页签切换部件、分析对象、重切片对象和软组织对象。列表可显示名称、可见性、连接/拓扑、变换和质量等信息；字段过多时支持横向滚动。空列表需显示空状态提示和新增按钮。

### 6.3 STLs / Polylines / Simulation Objects / FEA Mesh

管理 STL 模型、折线、仿真对象和有限元网格。对象行显示名称、可见性、实体数/三角面数、变换状态和质量检查状态；支持导入、复制、删除、导出及在三维视图中定位。

### 6.4 Contrast / Volume Rendering / Clipping / Snapping

底部使用 `Contrast`、`Volume Rendering`、`Clipping`、`Snapping` 四个页签。

- `Contrast` 显示灰度直方图和窗宽窗位曲线，底部提供灰度类型下拉框及 Min/Max 数值输入。
- `Volume Rendering` 提供预设、透明度、采样质量和颜色映射。
- `Clipping` 提供裁剪平面启用、方向和距离；`Snapping` 提供吸附目标与容差。
- 参数改变应实时更新视图，支持撤销/重做；长耗时渲染使用局部进度指示。

## 7. 底部项目与状态信息

左下角为项目日志/信息面板，按时间倒序显示项目编辑信息、创建/修改软件、当前动作和文件路径。时间戳使用 11~12 px 灰色文字，详情使用 12 px 深灰文字。面板支持折叠、滚动和复制；超长路径单行省略并在悬浮时显示完整内容。状态栏可显示坐标、渲染状态、未保存标记和后台任务进度。

## 8. 状态、反馈与异常

- **选中态**：列表行浅蓝背景，视图对象高亮描边，二者同步。
- **禁用态**：降低对比度但保持可读，禁止仅依赖颜色区分。
- **加载态**：切片、模型导入和渲染显示局部进度，保留已有内容。
- **空状态**：显示简短提示、所需操作和主按钮。
- **错误态**：就近显示原因、影响和恢复操作；导入失败时保留原列表。
- **未保存**：标题栏显示星号或状态点，关闭/切换项目时提供保存、放弃、取消。

## 9. 响应式与可访问性

- 右侧栏建议限制在 360~520 px；主阅片区每个视图至少 280×220 px，窄窗口时右侧栏可折叠为抽屉。
- 视图区网格在最小宽度下可切换为 1×4 纵向排列，桌面尺寸默认保持 2×2。
- 所有图标按钮提供 tooltip、键盘焦点和可访问名称；颜色标签同时显示文字名称。
- 文字、坐标和警示信息满足至少 4.5:1 对比度；红绿颜色不可作为唯一状态依据。
- 支持高 DPI 缩放，图标和线宽使用矢量资源，避免 125%/150% 缩放模糊。

## 10. 实现验收清单

- [ ] 三个正交视图可联动定位，十字线和坐标值同步更新。
- [ ] 遮罩列表的可见性、颜色、排序和删除操作可用，并反映到视图。
- [ ] 三维视图可旋转、平移、缩放和重置；对象选择可双向同步。
- [ ] 直方图窗宽窗位调整可实时影响影像显示，并支持撤销。
- [ ] 列表在空、加载、错误、选中和禁用状态下均有明确反馈。
- [ ] 1280 × 720 及 150% DPI 下无关键控件重叠或文字截断。
- [ ] 未保存修改、导入失败和删除对象均有可恢复的确认流程。

## 11. 待确认的产品规则

以下内容无法仅从设计图确定，开发前需产品或医学专家确认：

1. 各颜色对应的椎体标签及其色盲安全标准。
2. 坐标数值的单位、精度和正负方向约定。
3. 鼠标与键盘快捷键的最终映射，以及是否允许用户自定义。
4. 删除遮罩、网格和仿真对象时的权限与审计要求。
5. 体绘制、FEA 网格和仿真模块的性能目标及后台计算策略。
